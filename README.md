# е-Кабинет · Општина Битола

Веб-платформа за известување и следење на проектите, буџетот, ризиците, предметите и прашањата што бараат внимание
од **Градоначалникот на Општина Битола** (Република Северна Македонија).

Целиот кориснички интерфејс, известувањата, прирачникот, извозите и порталот за приватност се на **македонски јазик
(кирилица)**. Англискиот е достапен како втор јазик на интерфејсот.

> Ова е посебна, самостојна инсталација. Не содржи и не пренесува податоци од друга општина: базата на податоци
> се создава празна, со почетна организациска поставеност на Општина Битола, и се пополнува преку апликацијата.

## Главни модули

- Панел и агенда на Градоначалникот, неделни брифинзи (Градоначалник и сектори)
- Проекти, задачи, извештаи за напредок, документи, фотографии и GIS локација
- Буџет: одобрен буџет, распределби, обврски, расходи и буџетски промени со работен тек
- Регистар на ризици со превентивни мерки и резидуален резултат
- Управни предмети, препраќање со пропратен акт и Правна служба (досиеја, рочишта, рокови)
- Неделно известување за услугите за граѓаните (каталог на услуги по сектори и одделенија)
- Работни области на извршната власт, напредно следење и глобално пребарување
- Контролиран увоз (CSV/XLSX) со преглед и атомска потврда, извоз во Excel/CSV
- Ревизорски траги, известувања во апликацијата и по е-пошта (Microsoft Graph)
- Ограничени AI асистенти (OpenAI): извештаи од обичен јазик, брифинзи, прикачување Word/PDF/Excel извештаи
- Опционален панел на Градоначалникот во Google Sheets

## Технологија

- PHP 8.1+ без framework, HTML рендериран на серверот, прогресивен JavaScript — код во [`php81/`](php81/)
- Microsoft SQL Server 2019+ преку `pdo_sqlsrv`; сите текстуални колони се `NVARCHAR` (Unicode), а базата се
  создава со колација **`Macedonian_FYROM_100_CI_AS`** за правилно подредување и пребарување на кирилица
- Приватни датотеки надвор од document root (`php81/storage/private`)

| Патека | Содржина |
| --- | --- |
| `php81/public/` | Document root (единствената јавна папка) |
| `php81/app/` | Апликација (контролери, сервиси, безбедност) |
| `php81/database/` | `schema.sql`, `seed-production.sql` (почетни податоци за Битола) и миграции |
| `php81/bin/` | Команди: инсталација, миграции, распоредувач, дијагностика |
| `php81/config/e-kabineti.php.example` | Пример за приватната конфигурација |
| `deploy/` | Примери за Apache, Supervisor и SQL Server |
| `docs/` | Документација |

## Инсталација

Целосно упатство за инсталација и конфигурација од почеток (сервер, SQL Server, конфигурација, прв администратор,
Microsoft Graph, OpenAI, Google Sheets, распоредувач, резервни копии): **[docs/ИНСТАЛАЦИЈА.md](docs/ИНСТАЛАЦИЈА.md)**.

Кратко:

```bash
git clone https://github.com/brahaluftar/ekabineti.mk.git /var/www/ekabineti-bitola/repo
cp /var/www/ekabineti-bitola/repo/php81/config/e-kabineti.php.example /var/www/ekabineti-bitola/shared/e-kabineti.php
php /var/www/ekabineti-bitola/repo/php81/bin/preflight.php
php /var/www/ekabineti-bitola/repo/php81/bin/install-database.php
php /var/www/ekabineti-bitola/repo/php81/bin/migrate.php
```

## Тестирање

Единичните тестови не бараат база на податоци (користат SQLite во меморија):

```bash
cd php81 && for t in tests/*-unit.php; do php "$t" || exit 1; done
```

Интеграциските тестови (`tests/integration.php`, `tests/evidence-integration.php`) бараат посебна тест база на SQL Server
(името мора да содржи `test`) и конфигурација во `tests/local-config.php`.
